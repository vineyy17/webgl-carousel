# Infinite coverflow

WebGL image carousel built with React Three Fiber, custom plane shaders, and a light transmission layer.

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Controls

- Drag or scroll to move through the infinite strip
- Arrow keys to step one slide
- Click a slide to expand; click the backdrop or press Escape to close
